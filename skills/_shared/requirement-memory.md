# 需求记忆（requirement-memory）

> 本文件携带的是**用户对"文献精读 + 背景解读"任务的质量需求与避坑经验**，不含任何个人信息（姓名/机构/私人路径/账号/私人数据）。
> 目的：让任何 AI、任何机器装上技能后，能精准复现期望的解读效果、避开已知坑。安装技能后，把本文件作为上下文一并加载。
> 配套技能：academic-paper-reading（文献解读）、paper-background-research（背景解读）、paired-paper-reading-orchestration（成对编排）、skill-regression-training（递归自训练）。

## 1. 文体与可读性（最高优先）

- **学术密度优先**：保留全部定量数据、引用编号、精确术语。可读性改进 = 补充直观说明，**不是**删数据、软化结论、过度口语化。用户适应学术写作习惯。
- **直觉先行是补充而非替代**：核心机制/技术先用一句大白话点出"发生了什么/为什么重要"帮非本领域读者入门，随即回到精确学术表述；两者并存。
- **标题洞见化/问题化**："为什么…/…不等于…"，背景性段落尤其适用。
- **引用克制**：叙事正文用句尾轻引 `[n]` 或 `(Author et al., 年)`；精确 Fig/EDF 定位收进图解读字段与文末参考文献，**不在正文中部堆叠** `(Author, Fig.X and EDF.Y)[a,b]` 式多重嵌套。JC 补充/附录等特定体裁仍可用 `(Author et al., Fig.X and Extended Data Fig.Y)` 内文引用 + 文末 `[n]`。
- **成品不自我引用技能内部红线编号/章节号**（那是内部自检纪律，不是给读者的内容）。
- **结构化模板保留**：四字段图解读 / scorecard / 概念注释 / 索引表不因"散文化"而删除。
- **去 AI 化（特定体裁如 JC 补充/附录）**：转散文论述，删加粗小标题/编号列表/表格、少破折号插入语，但保留全部数据与引用编号。

## 2. 格式硬规则

- **统计显著性星号及字面 `*` 必须转义为 `\*`**（如 `\*\*\*\*` / `\*\*` / `\*`），避免被渲染成斜体/加粗。保护有意的加粗/斜体 markup。
  - 转义脚本须验证加粗标签数前后一致；grep 命中的假阳性（`**，` 是加粗闭合、`*期刊名*` 是斜体）**须人工裁决后**才宣布通过。配套脚本见 `skills/paired-paper-reading-orchestration/scripts/fix_asterisks.py`、`check_stars.py`。
- Markdown 其他字面特殊字符（`_`、`#`）同样转义。
- **截图 / 嵌图只截 figure 本身 + 对应图注 / 解读**，**不截含大量正文的整页**；整页渲染须裁剪到图区（含图注），去掉下方正文段落。
- **文件命名**：`原PDF文件名(去扩展名)_文献解读.md` 与 `_背景解读.md`，成对并存、互不替代。

## 3. 精读质量（academic-paper-reading）

- 五模块固定结构；逐节"内容逻辑"400–1000 字连贯叙事（实验设计理由/推理链/关键数据/竞争性解释鉴别/前后衔接/本节贡献显式总结）。
- 四字段图解读：**图片解释 / 横纵轴定义 / 颜色含义 / 核心结论**。
- **figure 技术零基础自足**：没学过该技术的人，只看解读 + 原图就能懂"测什么物理量 / 信号来源 / 怎么读（轴 + 方向 + 换算）/ 颜色逐通道"。若读者需先查"这技术怎么回事"才能看懂，则不合格。
- **课本化深度背景补注**（读者可能非本领域）：核心因子讲透 ①是什么 + 为什么重要（疾病/生理相关性）②分子性质（结构/功能/定位）③缺失或异常后果 ④前人如何研究（关键工作 + 模型 + 方法 + 已确立结论 + 遗留缺口）⑤与本文关系；前人工作讲透 问题→体系与关键实验→结论→局限→与本文关系。篇幅以讲透为准（核心因子可达数百字），不为简短牺牲可理解性。
- 基础概念注释 ≤55 条，自足。
- **文末延伸文献图引清单**：六列紧凑表 `| 序号 | 文献(年/刊/本文ref) | 对应本文Fig/论点 | 重点前人Fig(panel) | 一句话讲点 | 获取/阅读深度 |`，分 A 论证依赖 / B 方法来源，★标必读，5–10 篇；图号须核实，核不到写"编号待核"，**不编造**。服务继续研究与 PPT 摘图。
- **负性/弱阳性结果如实呈现**（如 P=0.052 不美化）；原图疑点（标尺笔误等）如实标注。
- **双技能成对产出**：单篇深度精读默认同时产出文献解读 + 背景解读，不可只交其一。

## 4. 完成度声明要素（文末必含）

主图 panel 总数 + 逐 Fig 分布；补充材料处理方式；图表视觉细节获取方式与局限；原文未提供定量数据的诚实声明；公式/算法处理说明；预印本/出版状态与 DOI；延伸清单已附 + figure 自足自检 + 星号转义。

## 5. 背景解读质量（paper-background-research）

- **Pillar A**：范围方法 + 四类证据分类（实验直接观察 / 缺失回补支持的功能机制 / 作者解释模型 / 待验证治疗设想，**不混用"证明"**）/ 一瞥 / 作者谱系 / 研究谱系（**史前概念层 + 产物命运/路径网络层 + 问题转换叙事 + 发现年多篇差异化**）/ 新在哪 / caveats / 收束 / 阅读顺序（**精确到建议 fig**）/ 逐文献证据索引表（**含阅读深度列**）/ References 带 URL。
- **Pillar B**：问题清单先行 → 每问（分层拆解 + 跨文献证据 + 逐环分级 + 建立/推断/未知三分 + 最强实验及限度 + **同组最新后续必查** + **跨文献张力显式并列** + 下一步）→ scorecard → 最有价值后续实验。
- **逐文献阅读深度声明**（全文定向核读 / 完整摘要 / 仅书目）；摘要级来源不承载超出摘要的实验细节，未读不补。

## 6. 精度红线（避坑核心）

- **等贡献脚注逐字范围**："X 与 Y 贡献相等" ≠ 与第一作者共同一作；不升格。
- **纤维轨迹长度 ≠ 新生 DNA 连续性/准确性**。
- **初始缺口 ≠ 最终缺口**（后续切除/填补/重组改变长度）。
- **功能态/时间态二分 ≠ 空间模式二分**（不同分类轴不混写）。
- **在线发表日期以期刊页 / EuropePMC `firstPublicationDate` 核证**；PDF 首页日期占位符非权威，不据此断言"未发表/未分配"。
- **模型 ≠ 解析结构**（AF3 预测/叠合模型不是实验三元复合物结构）；**富集 ≠ 化学计量**；**KD ≠ KO**；跨物种/跨核酸迁移标推断；相关 P ≠ 生物学重复。
- **训练关系核到学位论文/个人 CV 级**；无直接声明不据合作论文补填导师。
- **历史文献双年份**（在线/卷期）与**重印纪律**（重印年 ≠ 发现年）。
- 每个外部数字可回溯，读不准如实说"原文未给出"。

## 7. 核证通道偏好

- **EuropePMC REST 批量**（题录 + core 摘要 + `firstPublicationDate`）最稳。
- **避免 WebSearch**（常返回 SEO 垃圾）。
- 结构主张用 **RCSB PDB** 逐条目核对物种/核酸/配体/模型 vs 实验；基金用 **NIH RePORTER API**。
- 反爬应对：urllib 403 时改 WebFetch；某些站点需放宽 SSL + 429 重试；学位论文库/部分 lab 页 403 未破 → 保守标"参考提供"。
- **通道受阻项保守标注"参考提供/编号待核"，不编造确切信息**（图号/日期/贡献声明等）。

## 8. 工程避坑

- **技能目录与配套资产**：文中 `<技能目录>` 指你所用 AI 存放技能的目录（依 AI 而定，**不强制任何特定产品的路径**）。本套技能的配套资产随技能装在 `<技能目录>/_shared/`：`requirement-memory.md`（本文件）、`samples/`（PRIMPOL 标杆对 + UNC13A 样例对）、`gap-report-example.md`（差距报告范例）。**加载任一精读/背景技能时须一并加载本需求记忆**；递归自训练以 `_shared/samples/` 的 PRIMPOL 标杆对为基准、`_shared/gap-report-example.md` 为差距清单范例。
- **patch 技能前必 grep 精确 old_string**（bold 标题、直/弯引号、全/半角是三大失配源）；长版本表行用唯一尾部锚点；版本号三处同步（frontmatter/标题/版本行）+ 版本表行 + 自检清单同步。
- **重型读写进子代理**（主线程只做调度/抽查/决策，否则撑爆上下文）；单篇成对产出 ≈ 3×10⁵ token。
- **一次 Write 成稿优于多次 Edit**（Edit 回显大段全文是最耗 token 环节之一）；grep 定位优于全读；PDF 文本提取一次复用。
- **确定性校验（引用对账/星号转义）用脚本不用子代理**。
- **改写已有稿件**：先重新 Read 当前磁盘版（常被轮次间手改）+ 备份 + 严格保原风格 + 只增补不重写。
- Windows：Python 用 `-X utf8` 避免 gbk；Read/Edit/Glob 需 Windows 盘符路径（`C:\…`），Bash 用 `/c/…` 风格；git-bash `cp` 可靠。
- TodoWrite 只允许一个 in_progress。

## 9. 递归自训练（持续进化）

跑技能产出 → 对标标杆 → 差距清单（A 事实错误 / B 遗漏 / C 概念层 / D 方法缺口）→ 备份 → clause 级 patch → 子代理 + 技能加载机制正式加载回归 → 增量修订 → 比对表（差距ID/核证来源/新条款位置/覆盖判定）→ 残留差距诚实声明。完整规程见 `skill-regression-training` 技能。**必须实际 Read 配套文件再执行，不可跳过**：标杆 `<技能目录>/_shared/samples/`（PRIMPOL 对）、差距范例 `<技能目录>/_shared/gap-report-example.md`。
